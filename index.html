例文・表現を追加

英文の次の行に和訳を書きます。空行で区切ったブロックが練習の1単位になるので、会話や長文は続けて書けば通しで練習できます。
A: のように行頭に話者名を付けると、2つの声で読み分けます(全行に付けたときだけ有効)。

登録済み

ElevenLabs API

APIキーはこの端末のブラウザにのみ保存され、GitHubには送信されません。

話者ラベル付きのスクリプトは、1人目の話者を話者1の声、2人目を話者2の声で読み上げます。未設定のときはすべて話者1の声になります。

文の長押し

和訳のパネルでは英文を選択できるので、そこから単語を長押しすればiPhoneの「調べる」「翻訳」も使えます。
iPhoneの辞書で和訳を出すには、iOSの設定 → 一般 → 辞書で「ウィズダム英和辞典」などの英和辞典にチェックを入れてください。長押しメニューの「翻訳」は辞書の設定なしで使えます。

Claude API(日本語訳・語彙)

入力すると日本語訳と、上で「Claudeの語彙解説」を選んだときの語彙解説が使えます。空のままでも音声機能は動きます。

データ

生成した音声はこの端末に保存され、次回以降はAPIを使わず再生されます。

ホーム画面に追加

ブラウザの共有ボタンから「ホーム画面に追加」を選ぶと、アプリのように全画面で起動できます。
