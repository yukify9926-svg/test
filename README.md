# シャドーイング練習アプリ

自分で入力した英語の例文・表現をもとに、ElevenLabsのText-to-Speech APIで音声を生成し、シャドーイング練習をするための個人用Webアプリです。ビルド不要・サーバー不要のシンプルな静的サイトです。

## 使い方

1. `index.html` をブラウザで開く(またはローカルサーバーで配信する)。
2. 「設定」タブで ElevenLabs の API Key と Voice ID を入力して保存する。
   - API Key: https://elevenlabs.io のアカウントページから取得できます。
   - Voice ID: ElevenLabsのVoice Library、または自分のアカウントの音声一覧から取得できます。
   - **API Keyはこのブラウザの `localStorage` にのみ保存され、リポジトリにはコミットされません。**
3. 「スクリプト一覧」タブで、覚えたい例文・表現を追加する。
4. 「シャドーイング練習」タブでスクリプトを選び、「音声を生成」で音声を作成して再生。再生速度の調整・リピート再生ができます。
5. 練習したら「練習済みにする」を押すと、練習回数・最終練習日が記録されます。
6. 「未練習を次へ」ボタンで、最も長く練習していないスクリプトから順に練習できます。

## データの保存とGitHubでの同期

スクリプトデータは通常ブラウザの `localStorage` に保存されます。複数端末で使う場合やバックアップしたい場合は、「設定」タブの「JSONをエクスポート」でデータを書き出し、`data/scripts.json` として保存してこのリポジトリにコミットしてください。別の端末では「JSONをインポート」で読み込めます。

`data/scripts.sample.json` にはサンプルデータが入っており、「サンプルデータを読み込む」ボタンで試しに読み込めます。

## ローカルサーバーでの起動(任意)

`fetch` でサンプルJSONを読み込む機能があるため、ブラウザによっては `file://` から直接開くと動作しない場合があります。その場合は簡易サーバーを使ってください。

```bash
python3 -m http.server 8000
# その後 http://localhost:8000 を開く
```
