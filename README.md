# シャドーイング練習アプリ

自分で入力した英語の例文・表現をもとに、ElevenLabsのAPIで音声を生成してシャドーイングを練習するための個人用Webアプリです。ビルド不要・サーバー不要の静的サイトで、GitHub Pagesで公開してスマートフォンから使えます。

公開URL: https://yukify9926-svg.github.io/test/

## 主な機能

**練習**
- 再生中の文をハイライト表示(ElevenLabsの文字単位タイムスタンプを使用)
- 対話は話者ごとに声を出し分け(Voice IDを2つ設定)。話者ごとに生成した音声をつなげて1つの録音にするため、通しで再生・シークできます
- 文をタップするとその位置から再生
- 文を長押しすると、その文の和訳をパネルに表示(未登録ならClaude APIで生成)
- 長押しの動作は設定でiPhoneの「調べる」「翻訳」にも切り替え可能

  和訳パネルの英文は選択できるので、そこから単語を長押しすればiPhoneの辞書も使えます。iPhoneの辞書で和訳を出すには、iOSの設定 → 一般 → 辞書で英和辞典を有効にしてください。
- 5秒戻る / 5秒進む、シークバー、0.5〜1.25倍の速度調整
- リピート再生と、聞き取りにくい箇所を繰り返すA-B区間リピート
- 練習回数と最終練習日の記録、前後のスクリプトへの移動

**スクリプト管理**
- 英文と和訳を1つの欄にまとめて貼り付けると、行ごとに対応させて登録(和訳を用意していればClaude APIは不要)
- 空行で区切ったブロックが練習の1単位。会話や長文を通しで練習できる
- メモ・タグの付与、キーワード検索
- JSONでの書き出し / 読み込み

**画面設計**
- 英文をコンテンツ層として大きく表示し、操作系は下部の半透明なコントロール層に退避
- 速度・リピート・A-B区間・練習記録は「⋯」で開くパネルにまとめ、通常は前後移動と再生だけを表示
- 音声が未生成のスクリプトでは「音声を生成」のみを提示

**その他**
- 生成した音声と単語タイミングを端末内(IndexedDB)に保存するため、同じスクリプトを再生してもAPIを消費しない
- ホーム画面に追加すると全画面のアプリとして起動(PWA)
- ダークモード対応

## 使い方

1. 公開URLをブラウザで開く
2. 「設定」タブでElevenLabsのAPI KeyとVoice IDを入力して保存
   - API Key: https://elevenlabs.io/app/settings/api-keys で発行。権限は「テキスト読み上げ」のみで動作します
   - Voice ID: ElevenLabsの **My Voices** にある音声のIDを使用してください。無料プランではVoice Libraryの音声をAPIから利用できません
   - Voice ID(話者2)を入れると、話者ラベル付きのスクリプトを2つの声で読み分けます
   - APIキーはこの端末のブラウザ(localStorage)にのみ保存され、リポジトリには含まれません
3. 和訳の自動生成も使う場合は、同じ画面でAnthropic API Keyを入力(https://platform.claude.com/settings/keys で発行)。空のままでも音声機能は使えます
   - Claude Opus 5 を使用。1文あたり約0.7円(入力 $5/100万トークン、出力 $25/100万トークン)。結果は端末に保存されるため、同じ文で再課金されません
4. 「スクリプト」タブで練習したい英文を追加
5. 「練習する」→「音声を生成」で再生開始

## スクリプトの入力形式

「スクリプト」タブの入力欄に、**英文の次の行に和訳**を書いて貼り付けます。**空行が項目の区切り**で、空行までの範囲がまとめて1つの練習単位になります。

```
A: Hey, do you have a minute?
A: ちょっといいですか?
B: Sure, what's up?
B: もちろん、どうしました?
A: I wanted to ask about the schedule.
A: スケジュールについて聞きたくて。

Thanks, that really helps.
ありがとう、助かります。
```

上の例は2項目です。1つ目は3ターンの会話がまとめて1項目になり、通しで練習できます。

- **和訳は省略可**。英文だけの行はそのまま登録され、あとからClaude APIで翻訳できます
- **英文から始める**必要があります(日本語の行は直前の英文に紐づくため)
- 英文をすべて並べたあとに同じ数の和訳を並べる書き方も認識します
- **空行で区切ったブロックが練習の1単位**です。会話は1ターン1行で続けて書けば、全体が1つの音声になり通しでシャドーイングできます
- 空行を入れると、そこで項目が分かれます(場面の切り替わりなどに)
- 行頭に `A:` のように話者名を付けると、1人目を話者1の声、2人目を話者2の声で読み上げます。**全行に付けたときだけ**有効です(文中のコロンとの誤認を避けるため)。ラベルは読み上げられず、画面表示のみに使われます
- 「登録の単位」で分け方を変えられます

  | 単位 | 結果 |
  | --- | --- |
  | ブロックごと(既定) | 空行で区切られた範囲が1項目。会話・長文向け |
  | 1行ごと | 1行が1項目 |
  | 1文ごと | 行の中もさらに文で分割 |

行が言語の区切りになるため、1つの文の途中で改行しないでください。

## データの保存

スクリプトはブラウザのlocalStorage、生成音声はIndexedDBに保存されます。別の端末に移したい場合は「設定」タブからJSONを書き出し、移行先で読み込んでください。

## ローカルでの実行

```bash
python3 -m http.server 8000
# http://localhost:8000 を開く
```

## ファイル構成

| ファイル | 役割 |
| --- | --- |
| `index.html` | 画面構造 |
| `style.css` | スタイル(モバイル向けレイアウト、ダークモード) |
| `app.js` | 再生・ハイライト・データ管理 |
| `manifest.json` | ホーム画面に追加するためのPWA設定 |
| `vendor/anthropic.js` | Anthropic公式SDKをブラウザ向けにバンドルしたもの |
| `data/scripts.sample.json` | サンプルスクリプト |

### vendor/anthropic.js の更新

日本語訳と語彙解説は[Anthropic公式TypeScript SDK](https://github.com/anthropics/anthropic-sdk-typescript)を使っています。アプリ自体はビルド不要にしたいので、SDKだけを事前にバンドルして同梱しています。更新するときは以下を実行してください(現在同梱しているのは v0.117.1)。

```bash
npm install @anthropic-ai/sdk esbuild
echo 'export { default } from "@anthropic-ai/sdk";' > entry.js
npx esbuild entry.js --bundle --format=esm --platform=browser \
  --conditions=browser,import --external:node:* --minify --outfile=vendor/anthropic.js
```
